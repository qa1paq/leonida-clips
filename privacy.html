Leonida Clips Publisher – Privacy Policy

Last updated: November 20, 2026

Leonida Clips Publisher ("the app") is a personal desktop tool operated by the owner of the Leonida Clips channels (@leonidaclipspot). It uploads short, credited highlight clips of GTA 6 live streams, edited by the owner under the streamers' official clipping programs, to the owner's own accounts on YouTube, Instagram and TikTok.

YouTube API Services

The app uses YouTube API Services to upload videos to the owner's own YouTube channel. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

YouTube data the app accesses through the YouTube Data API v3:

  • videos.insert (scope youtube.upload): uploads a video file with its title, description, tags and privacy status to the signed-in channel.
  • channels.list with mine=true (scope youtube.readonly): reads the signed-in channel's ID and title once, only to confirm that the owner signed in to the correct channel.

The app does not read, collect or store data about any other YouTube users or viewers, and does not display or embed YouTube videos.

What data the app uses

  • OAuth access and refresh tokens issued by Google (YouTube), Instagram/Facebook and TikTok for the owner's own accounts.
  • Basic account information returned by these platforms (account ID and username), used only to publish videos.

How data is used, stored and shared

All tokens and settings are stored only on the owner's personal computer, in a local file. The app has no server, uses no cookies or tracking, does not sell or share any data with third parties and does not use data for advertising. Channel information read from the YouTube API is used only during the sign-in step and is not retained.

Revoking access and data deletion

  • Google / YouTube access can be revoked at any time on the Google security settings page.
  • Instagram/Facebook and TikTok access can be revoked in the security / app-permission settings of each platform.
  • When access is revoked, or on request to the contact below, all stored tokens and any YouTube API data are deleted from the owner's computer within 7 days. Deleting the app's local secrets folder removes all stored tokens immediately.
